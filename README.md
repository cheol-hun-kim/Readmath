# 📐 RootMath (루트매스) - AI 시각화 수학 멘토 & 국가수학교육과정 준수 엔진

> **"모든 수학 문제는 몇 가지 개념의 조합일 뿐이다. 상위 교육과정의 공식을 남용하지 말고, 해당 학년의 개념과 도식화(그래프/도형)로 증명하라."**

## 🏛 1. 대한민국 국가수학교육과정 엄격 격리 규칙 (Curriculum Isolation)

RootMath는 초등 1학년부터 고3/N수까지 **해당 학년의 정규 교과과정 범위를 철저히 지키며, 상위 학년의 공식(선행)을 끌어오지 않습니다.**

| 단계 | 학년 구분 | 공식 허용 교육과정 범위 | 🚨 절대 사용 금지 상위 개념 (선행 차단) | 권장 시각화 도구 (SVG) |
|---|---|---|---|---|
| **초등 저학년** | **초1, 초2** | 100~네자리 수, 가르기와 모으기, 덧셈/뺄셈, 구구단(초2), 모양 직관, 시계 | 구구단(초1), 음수, 문자식($x, y$), 분수, 나눗셈, 각도 | 바둑알, 사과, 수막대, 타일 배열 |
| **초등 중·고학년** | **초3 ~ 초6** | 분수/소수 사칙연산, 약수/배수, 통분, 다각형 넓이, 비와 비율(초6), 원의 넓이, 입체도형 | 음수 부호($-$), 문자식, 일차방정식 이항 공식 (선분도/바 모델로 해결) | 피자/초콜릿 분할, 수직선 띠 모델, 전개도 |
| **중등 과정** | **중1 ~ 중3** | 정수/유리수, 일차/이차방정식, 일차/이차함수, 피타고라스, 삼각비, 원주각 | 고등 복소수($i$), 삼차방정식, 수1 일반각 삼각함수, 미적분 도함수 | 격자 좌표평면, 도형 작도/닮음비, 피타고라스 정사각형 |
| **고등 공통수학** | **고1** | 다항식, 복소수, 이차방정식/이차함수(대칭축, 판별식 $D$), 도형의 방정식, 합성/역함수 | **수2 미분($f'(x)=0$으로 극값 구하기 절대 금지 - 완전제곱식/기하 해결)** | 포물선 대칭축 이동, 원과 직선 위치관계 |
| **고등 일반선택** | **고2** | 수학I (지수로그, 삼각함수 호도법/사인법칙/코사인법칙, 수열), 수학II (극한, 다항함수 미적분) | 초월함수 미적분, 치환/부분적분, 기하 벡터 | 3차/4차 극대극소 개형, 삼각함수 단위원, 정적분 넓이 |
| **수능·내신 파이널** | **고3 / N수** | 공통수학 + 수1 + 수2 + 선택과목 (미적분/기하/확통) 전 범위 수능 킬러/준킬러 추론 | 대학 수학 (로피탈 정리 지양 - 교육과정 정의 입각 증명) | 다단계 조건 해석, 도함수 부호 판별, 기하 벡터 |
